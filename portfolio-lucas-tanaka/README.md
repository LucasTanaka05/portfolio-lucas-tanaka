
# Portfólio Pessoal - Lucas Tanaka

## Sobre o projeto

Este é meu portfólio pessoal, desenvolvido como
atividade do curso de Engenharia de Software
da UniFil.

O objetivo é apresentar minhas informações,
projetos e formas de contato.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Páginas do site

- Início: apresentação pessoal e habilidades.
- Projetos: trabalhos e atividades desenvolvidos.
- Contato: links para minhas redes sociais e e-mail.

## Funcionalidades

- Menu de navegação entre as páginas.
- Estilização com CSS.
- Animações e efeitos visuais.
- Botão interativo utilizando JavaScript e DOM.
- Links para GitHub, LinkedIn e e-mail.
